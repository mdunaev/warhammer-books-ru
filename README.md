# Скрипторий — карта книг 40K

Интерактивная инфографика по книгам Warhammer 40,000 и Ереси Хоруса. Работает в браузере, без сервера и без базы данных.

Неофициальный фанатский проект, не связан с Games Workshop и Black Library.

## Как открыть

Дважды щёлкнуть по `index.html`. Нужен интернет: шрифты, обложки и библиотека графиков d3 грузятся с внешних сайтов.

Или запустить простой сервер из папки проекта:

```bash
python3 -m http.server 8765
```

и открыть http://localhost:8765.

## Разделы

- **Библиотека** — все книги. 10 сортировок, 9 группировок, фильтры (мир, эпоха, фракции, темы, место в галактике, перевод, формат, мои отметки, годы). Три вида: обложки, корешки на полке, список. Фильтры сохраняются в адресе — подборкой можно поделиться ссылкой. «Подобрать книгу» — короткий опрос.
- **Хронология** — река времени по эпохам, годы выхода, график «когда написано и когда происходит».
- **Галактика** — книги-звёзды по секторам. «Проиграть историю» зажигает их в порядке событий.
- **Пути чтения** — маршруты в виде линий метро с прогрессом.
- **Обзор** — фракции, оценка против популярности («скрытые жемчужины»), авторы, эпохи, темы, переводы.
- **Мои книги** — прочитано, «хочу прочитать», свои списки, статистика, барабан случайной книги. Списком можно поделиться ссылкой.

Отметки хранятся в `localStorage` этого браузера. Перенос на другое устройство — кнопки «Сохранить файл» и «Загрузить файл».

## Устройство

```
index.html          каркас страницы
css/style.css       оформление (тёмная и светлая темы, адаптив)
js/core.js          помощники и личные данные читателя
js/data.js          справочники, фильтры, сортировки, группировки
js/ui.js            обложки, карточки, эффекты
js/modal.js         окно книги, подбор книги
js/views/*.js       разделы
js/app.js           маршруты и шапка
data/config.js      настройки (рубильник обложек)
data/meta.js        эпохи, фракции, сектора, темы
data/books.js       готовые данные (генерируются, руками не править)
tools/              скрипты сбора данных
data/raw/           подробности по книгам, разбитые на пачки
data/sources/       выгрузка Fantlab, черновые списки, обложки
```

## Как обновить данные

```bash
node tools/fetch-fantlab.mjs      # скачать циклы с Fantlab -> data/sources/candidates.json
node tools/draft-list.mjs         # черновой отбор книг -> data/sources/draft-list.md
node tools/finalize-list.mjs      # финальный список, переводы, пачки -> data/raw/in/*.json
# подробности по книгам пишутся в data/raw/<пачка>.json по правилам data/raw/_SPEC.md
node tools/validate-chunk.mjs data/raw/*.json
node tools/covers.mjs             # обложки и число страниц -> data/sources/covers.json
node tools/build-data.mjs         # собрать data/books.js
```

Пути чтения: свои маршруты и их порядок — в `tools/paths-curated.json`.
Книги «Можно начинать с неё» (ленточка «Начни здесь») — ручной список в `tools/entry-curated.json`.

Обложки и толщина берутся только у отдельных изданий книги. Сборники (омнибусы) пропускаются: издание считается сборником, если оно общее у нескольких книг каталога, называется как сборник из каталога или толще 760 страниц и называется иначе. У самого сборника его собственное издание остаётся.

Состав сборников (названия, тип, год, авторы) берётся с Fantlab. Поиск находит сборник по рассказу внутри, а в окне сборника есть список «Что внутри». Сборник, которого нет в циклах Fantlab, добавляется по номеру в `EXTRA_IDS` в `tools/finalize-list.mjs`.

`build-data.mjs` в конце проставляет в `index.html` отпечатки файлов (`style.css?v=…`), чтобы после обновления браузеры не показывали старую версию из кэша.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить туда папку проекта.
2. В настройках репозитория: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<имя>.github.io/<репозиторий>/`.
4. Вписать этот адрес в `publicUrl` в `data/config.js` — тогда ссылки «поделиться списком» будут вести на сайт, даже если вы открыли его файлом с диска.

Папка `data/sources/fantlab/` (сырой кэш Fantlab) исключена в `.gitignore`: в ней чужие тексты аннотаций.

## Авторские права

- Тексты описаний написаны для этого сайта. Аннотации издателя и Fantlab не копируются.
- Логотипы и арт Games Workshop на сайте не хранятся. Знак проекта и эмблемы нарисованы с нуля.
- Обложки не хранятся в проекте. Они загружаются с Fantlab и Open Library для узнавания книг.
- Если правообладатель попросит убрать обложки: в `data/config.js` поставить `realCovers: false`. Сайт сразу перейдёт на свои обложки, нарисованные кодом.
- Сайт бесплатный, без рекламы. В подвале — пометка «неофициальный фанатский проект».

## Ограничения данных

- Lexicanum был недоступен для автоматического чтения. Часть дат внутри вселенной оценена по обзорам и вики. Такие даты помечены «примерно».
- Сектор галактики для некоторых планет угадан по контексту.
- Оценки — с Fantlab, то есть мнение русскоязычных читателей. У новых книг оценок мало.
